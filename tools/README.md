# Herramientas de operación (Windows)

El lanzador de uso diario es **`Iniciar Anka.bat`** (en la raíz del proyecto) y la verificación completa es
**`check.bat`**. Aquí viven los scripts de apoyo; todos se pueden ejecutar con doble clic.

| Script | Para qué |
|---|---|
| `Instalar autoarranque.bat` | Hace que Anka arranque sola al iniciar sesión en Windows. |
| `Quitar autoarranque.bat` | Deshace lo anterior. |
| `Piloto borradores Gmail.bat` | Piloto de Python para los modos `local` y `api` (en modo Work no se usa). |
| `legado/` | Lanzadores anteriores que ya sustituye `Iniciar Anka.bat`; se conservan por si alguien tenía un acceso directo. |
